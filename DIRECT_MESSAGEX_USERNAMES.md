# Direct MessageX usernames

Asteroid OS v0.99.23.4 removes the Contacts prerequisite from Comet messaging.

- `Message henry saying the build is ready` resolves directly to MessageX username `henry`.
- `Message @henry saying the build is ready` behaves identically.
- Saved Asteroid Contacts still provide friendly display-name aliases.
- Message sending remains invisible and uses the exact top confirmation banner.
- Invalid values containing spaces or unsupported characters prompt for the exact MessageX username.
